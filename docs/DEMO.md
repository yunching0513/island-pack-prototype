# 12/3 簡報 Demo 腳本（草稿）

> 草稿，2026-11-28 由每日開發排程依 issue #33 起草。還沒在簡報用的裝置上試過，也還沒錄備援影片；順序與講稿請團隊改。

**目標：** 三分鐘內講完「讓牠們回家，讓牠們回來」：一隻貓的回家旅程，加上同一區野生動物紀錄的增加。

**開始前**

- 用手機（或桌機開 375px 寬）打開公開網址 https://yunching0513.github.io/island-pack-prototype/ ，重新整理一次，確認外框版本號是最新的。
- 按外框的「重設原型」，指標回到示例初始值（回家 52%）。
- 教學提示若出現，先按「不用了」，簡報時從首頁開始。
- 網路不穩時改播備援影片（待錄，見 #33）。

## 一、首頁：兩個共同指標（約 30 秒）

1. 停在首頁。講：「每個地區只有兩個共同指標。『回家』是已經回家或進入最後一代的比例；『回來』是每小時散步記錄到幾種野生動物。」
2. 指出「最後一代」那段：「不適合家庭的貓狗，絕育後由照護者守護到終老。絕育是止血，不是結局。」
3. 強調：「沒有個人排行榜，地圖上也看不到其他玩家。」

## 二、一隻貓的回家旅程（約 90 秒）

1. 在「附近的牠們」點 **麒麟**（第 3 關）。講：「每隻動物一張個體卡，位置只到地標一帶。」
2. 指出六關：被看見、被認識、被照顧、準備好、回家、回訪。「每一關由不同角色確認。」
3. 示範 **資訊分級**：切到「小隊」，多了大致範圍與日記；講：「餵食點只有照護者看得到，原型裡不放任何座標。」
4. 由中途確認「準備好」→ 送出認養申請（三題都答「是」）。講：「這不是先到先得，中途會和每位申請人聊過。」
5. 行前清單五項打勾 → 「接牠回家」。講：「參與的每個人拿到同一枚回家徽章。」
6. 回首頁，指出「回家」從 52% 前進，並寫出原因。

## 三、野生動物回來（約 45 秒）

1. 點「相遇」→ 選野生動物 → 選 **黑冠麻鷺** → 送出。講：「貓狗和野生動物用同一個相遇入口。」
2. 第一次記到這一種，解鎖物種卡。講：「物種卡只講紀錄與努力量，不寫族群數量。」
3. 打開物種卡頁的「同一區半年的回來紀錄」，指出每小時物種數逐月上升（示例）。
4. 補一句：「石虎這類敏感物種，公開只到行政區，並延後 30 天。」

## 四、收尾（約 15 秒）

講：「受傷或受困的動物不進遊戲、不計分，直接導向緊急窗口。」可以點相遇裡的「牠看起來受傷或受困」示範，110、119 可直接撥號。
